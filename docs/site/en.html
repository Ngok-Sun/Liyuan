PART 01

Introduction & Installation

1.1 What is Liyuan?

Liyuan is an RP Agent that translates proven software engineering agent paradigms into creative storytelling and roleplay mechanics.

In traditional frontends, LLMs are merely passive completion endpoints that receive a single giant prompt and dump plain text. This inherently leads to setting drift, memory amnesia, and prompt bloat. Liyuan introduces an agentic loop, physical sandboxing, and artifact-based workflows:

Coding Agent Primitive Liyuan RP Equivalent Practical Mechanism
Workspace / cwd Isolated Card Space One physical folder per character card. Sessions, memory, and lore are completely aggregated; copy the folder to move.
Code Story Prose Narrative text treated as living creative output, supporting dual modes: Roleplay beats or Agent one-file-per-chapter.
Edit / Patch In-Place Targeted Revisions Surgically targets and modifies specific lines of prose without regenerating entire paragraphs from scratch.
Grep / Search Lore & Memory Retrieval The model actively inspects lorebooks and memory via tools before writing, keeping the active context window lean.
Rewind / Checkpoint Checkpoints & Snapshot Vault Content-addressable snapshot vault (历史/) tracking every revision with line-level diffs and instantaneous rollbacks.
Context Compaction Narrative Story Recap Summarizes past story beats into faithful recaps, archiving raw prose to storage while preserving recent dialogue word-for-word.
Permission Gate Fork Decision Cards (ask tool) Pauses at critical narrative branches to present interactive choices, letting you decide where the story heads.
SYSTEM / AGENTS Layered Prompts Transparent prompt layers (engine protocols, user guidelines, card world rules) with item-by-item toggleable controls.

1.2 Dual Creation Modes: Roleplay vs. Agent Mode

Liyuan provides two distinct, parallel creation workflows cleanly split in the session tree:

  • 🎭 Roleplay Mode: Focused on character immersion. Background operations and tool calls are enclosed. Story beats stream inside speech bubbles with cast rosters, state ledgers, and alternate worldlines.
  • 📖 Agent Mode: Akin to a coding agent. Discussions and prose are strictly separated: the chat pane serves as your collaborative discussion space, while prose is saved as standalone chapter files (正文/001-Title.md). The model edits files with native tools, supported by snapshots and line-level diffs.

1.3 Installation & Deployment Options

Choose from four deployment methods based on your environment:

Option 1: Desktop Application (Recommended)

Download prebuilt binaries from the GitHub Releases page:

Platform Package Notes
Windows Liyuan-*-win-desktop-setup.exe Standard installer with built-in auto-update detection.
Windows (Portable) Liyuan-*-win-desktop-portable.zip Extract and run Liyuan.exe directly. No registry changes.
macOS Liyuan-*-mac-desktop-arm64.dmg / -x64.dmg Apple Silicon and Intel builds. Unsigned; allow in System Settings on first launch.
Linux Liyuan-*-linux-desktop.AppImage Run chmod +x and execute directly.

Option 2: Docker Deployment (Recommended for Servers)

Pull official multi-arch images (amd64 / arm64) from GitHub Container Registry: 

mkdir -p liyuan && cd liyuan
curl -fsSL -o docker-compose.yml https://raw.githubusercontent.com/weidu12123/Liyuan/master/deploy/compose.ghcr.yml
docker compose up -d

# Upgrade to latest
docker compose pull && docker compose up -d

Data is persisted to ./data/ on your host. Image: ghcr.io/weidu12123/liyuan:latest.

Option 3: Run from Source

Requires Node.js ≥ 22:

# 1. Clone repository
git clone https://github.com/weidu12123/Liyuan.git && cd Liyuan

# 2. Prepare configuration
cp liyuan.agent.example.json liyuan.agent.json
cp liyuan.config.example.json liyuan.config.json

# 3. Install & Start
npm install
npm run web:build    # Build frontend
npm run web          # Launch server on http://127.0.0.1:7620
⚠️ Security Notice
Port 7620 has no authentication until an Access Password is set. When deploying publicly, immediately set a password in System Settings.
PART 02

Quick Start Guide

Step 1: Set an Access Password

Click the gear icon (Settings) in the bottom-left navigation bar. Under the "Access Password" card, enter at least 4 characters and save to secure your instance against unauthorized access.

Step 2: Connect Your Model API

Click the plug icon (Connect) on the navigation bar. Click "+ Generate Config" and enter your provider's API URL, key, and model ID:

  • Thinking Mode: Set to off for standard models; set to low or off for reasoning models (e.g. DeepSeek-R1).
  • Context Window: Set to 128000 (128k).
  • Max Output Tokens: Recommended 16384 (16k) to prevent truncated prose.
  • Streaming: Keep checked for real-time typewriter output.
Step 3: Pick a Character & Creation Mode

Click the character library icon in the top left:

  • For Roleplay: Choose a greeting branch in the left drawer and click "Start Chat".
  • For Writing a Story (Agent Mode): Click "New Project" and check "📖 Prose Agent" mode. The opening message automatically saves as 000-Opening.md.
Step 4: Co-create Characters with the Agent

Switch to "Work Mode" on the top header and type: "Help me create a cyberpunk detective card with skills and fill steps 01 and 02 in the Studio". The built-in card-authoring skill will orchestrate tools to create and save the card.

PART 04

FAQ & Best Practices

Q1: What are the differences between Roleplay, Work, and Agent Mode?
  • 🎭 Roleplay Mode: Focused on immersive play. Technical tool calls are hidden, prose streams inside chat bubbles, and the ledger tracks character affinity and state automatically.
  • 📖 Agent Mode: Tailored for long-form novel and script writing. Discussion and prose are strictly separated; prose saves as chapter files (001-Opening.md) with snapshots and line diffs.
  • 🛠️ Work Mode: Switch here mid-chat to modify the character card, debug regex scripts, or add entries. Once finished, switch back to Roleplay without polluting story context.
Q2: How does Liyuan ensure multiple projects under the same card don't leak or read each other?
Liyuan v1.6.5 enforces physical isolation:
  1. Sandbox Guard (isOtherChatPath): Native tools trying to read, edit, or grep another project's directory are intercepted and DENY-rejected at the sandbox layer.
  2. State Block Summary Isolation: Agent mode state blocks strictly prohibit cross-project resident summaries, ensuring fresh projects start with 0% contamination.
Q3: When I delete a project or session, is all memory truly forgotten?
Yes. Clicking the red trash can in the session tree triggers a 5-step physical cleanup:
  1. Recursively deletes the project folder (prose, snapshots, chats, ledger, vector store);
  2. Physically deletes the card-level recap file (记忆/局/<id>.md);
  3. Deregisters the project from the manifest and queues it for forgetting, wiping all facts from persistent summaries.
Deleting the currently active project automatically transitions you to another project or creates a fresh one smoothly.
Q4: Why must thinking mode be disabled for side models?
Side models asynchronously update ledgers, inventories, and rosters at the end of each turn. Structured updates must be fast. Enabling thinking causes unnecessary delays of 30-90 seconds per turn. Always set thinking to off for side tasks.
Q5: How do I troubleshoot HTTP 400 or Invalid Argument errors when connecting an API?
Verify three common issues:
  1. Thinking Mode: Non-reasoning models (e.g. GPT-4o, Claude 3.5 Sonnet) reject thinking parameters; set it to off.
  2. Base URL Format: Ensure your reverse proxy URL includes the required /v1 or /v1/ suffix.
  3. Context Window: Ensure the specified window does not exceed the model's actual physical limit.
Q6: How can I migrate character cards, sessions, and memory to another machine?
Liyuan uses physical workspace folders:
  • Per-card Migration: Copy the cards/CharacterName/ folder to your new device. All sessions, chapters, and memory are retained.
  • Full Site Backup: In "Settings → Backup and Restore", click "Export" to download a full zip snapshot. Import it on the new machine to restore everything in one click.
