# Liyuan Agent 1.6.4

## 新增

- **资产安全防线与系统回收站**：
  - 新增命令黑名单机制（内置并播种 `BASH_DENYLIST.txt`，前置拦截破坏性命令，用户可见可改）。
  - 新增资产安全快照仓（定时与 API 写删触发快照，SHA256 对象去重，自动保留 50 个检查点）。
  - 新增资产软删除机制与回收站（世界书、预设、角色卡删除转入回收站，支持一键还原与防硬删）。
  - 重构 bash 授权形态：撤除全局布尔总开关，改为按命令前缀白名单免问。
- **CLI 终端驱动模式**：
  - 支持终端直连模式（`--cli`），终端可直接驱动 Agent 创作模式与选择卡交互。

## 修复与优化

- **Agent 讨论压缩闭环**：
  - 讨论压缩判据改用真实 prompt usage，彻底根治大窗口下因中文字符估算偏低导致的讨论压缩永不触发、长局必定溢出崩溃的严重缺陷。
  - 手动 `/compact` 在 Agent 子项目中正确定向为讨论历史压缩（并设置 2000 token 安全地板保护）。
  - 正文文件压缩文案改名为「前情提要已刷新」，与「讨论已压缩」文案分家。
- **上下文指示器折算与压缩可见化**：
  - 修复压缩完成后状态栏上下文指示器停滞不刷新的缺陷，当拍按估算份额折算刷新（涵盖 Agent 讨论压缩与扮演拍压缩）。
  - 新增压缩全生命周期事件推送（`onCompaction`），状态栏常驻压缩计时，对话流内联生成可展开回读的摘要卡片。
